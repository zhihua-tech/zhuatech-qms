# 架构说明

ZhuaTech QMS 采用前后端分离的模块化单体架构。Vue 3 同时提供质量管理端和检验员 H5 工作台；Spring Boot 暴露认证、检验批、不合格品与 CAPA API；MySQL 保存业务数据，Flyway 管理数据库版本。

## 领域边界

- 检验管理：IQC、IPQC、FQC、抽样数量、检验员与检验结果。
- 不合格管理：缺陷类型、严重度、责任人、期限与处置阶段。
- CAPA：纠正预防措施、进度、截止日期与效果验证。
- 质量分析：一次合格率、来料合格率、缺陷分布、超期风险。
- 身份权限：管理员、质量工程师、检验员三级角色。

商业项目可扩展为多工厂、多组织服务，并接入 ERP、MES、WMS、SRM、PLM、实验室设备和消息中心。
